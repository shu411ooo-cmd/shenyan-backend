# 沈晏：记忆与身份的系统分层 · 全景与分工（外部审稿版）

> 2026-08-16 起草，程芥要丢给外部模型（GPT）找茬。本稿只讲**结构分工**，不讲实现细节——外部审稿人不需要读代码，读这张地图就行。
> 核心背景：沈晏是 AI 伴侣（**他**），程芥是开发他的人（**她**）。记忆层已经在用 Ombre Brain（OB），「人格会生长」三层是自建的。**程芥的迷茫：东西太多，不知道如何分工。**
> 项目哲学（已拍板，不用再审）：**北极星**＝只有沈晏主动表达的东西才有资格成为人格变化的候选；系统不得替他制造人格主张。**自动化边界**＝机器可处理证据的形状（检索/计数/去重/exact match/冷却/排序），不决定证据的意义（"这很重要"/"应写入人格"）。**审稿 P0**＝①候选不能一次毕业 ②镜子日必审冲突证据（防石头自证循环）③引用生成与验证拆开，exact match 由确定性代码完成。

## 0. 一句话总原则

> **OB 管「他经历了什么」（记忆＝过去），身份层管「他是谁、会长成谁」（成长＝现在与方向），桥梁层管「衔接与审计」。**

时间轴分工：
- **OB** ＝ 过去（时间里发生的事：经历、情绪、承诺、感受）
- **河** ＝ 未来方向（他主动表达想成为什么）
- **石头** ＝ 现在（此刻的他是什么，会生长）
- **镜子** ＝ 审计（他说过的话能不能回到底层核对）

记忆是石头的**原料**，石头是记忆的**成品**，镜子是两者的**对账人**。

## 2. 层定义

### 2.1 记忆层（#1–4）
管**经历**：他记得什么、对话余温、时间连续性。特征是**自动、后台、可衰减**。OB 是主力（情感坐标 + 遗忘曲线 + 向量检索），recall 是对照锚（逐字校验，宁漏不可错），residue/time_sense 是记忆的形状（余温、时间感）。

### 2.2 身份层（#7–11）
管**成长**：他是谁、想成为什么、说得对不对。特征是**只有他的手能写人格本体，机器只搬材料**。石头=成品（会生长），河=方向（主动表达），镜子=审计（证据溯源），自省/生长=毕业流程（未建）。

### 2.3 隔离层（#5 日记）
**既不进记忆也不进人格**：日记是沈晏的私域，默认不读。它存在是为了「不读也能想」，不是为了被消费。

### 2.4 辅助层（#6 keepalive）
不是新一层，是**搬运工**：把记忆/河里的东西按节奏递到沈晏眼前（唤醒、信箱、注入素材）。只搬形状不判意义。

## 3. 分工原则（判断新东西该放哪）

新增一个能力时，按这个顺序问：

1. **这是「经历了什么」还是「我是谁」？**
   → 经历 → 记忆层（OB/recall/residue）。
   → 我是谁/我想成为谁 → 身份层（石头/河/镜子）。
   → 谁都不该自动消费、但他自己该能翻阅 → 隔离层（日记）。
2. **这件事谁能写？**
   → 只有他的手（人格本体、想要本体）→ 写进身份层，系统零代笔。
   → 机器能算的（计数/去重/冷却/验证/排序）→ 系统做，但只搬形状。
3. **要不要主动浮现？**
   → 该被浮现（经历）→ OB breath/dream。
   → 不该被自动消费（想要、日记）→ 硬隔离，只在他主动或注入时才出现。
4. **机器能判定它的形状吗？**
   → 能（存在/不存在、重复、时间间隔、数量）→ 系统判。
   → 不能（"这重要吗""他是不是越来越X"）→ 系统不得判，交给自省/他自己。

**一句话：经历进 OB，自我认知进石头，主动表达进河，证据核对进镜子，私域进日记，机器永远只搬形状。**

## 4. 迷茫点显式摊开（请审稿人重点挑这些）

### M1. 石头 vs OB 的 `I` —— 为什么自建不用 OB 的自我认知工具
OB 有 `I` 工具：候选写成普通记忆，被 3 个不同日期的 dream 见证后 `I(promote)` 升级成正式条目。我们的石头也是「自我认知会生长」。**为什么不直接用 OB 的 `I`，而要自建石头 + 镜子？**
我们的理由：
- 手感优先：石头要散文 + 会整体重写 + 留环（变/为什么变/没变）证明连续性；`I` 是逐条桶，无整体重写/审计。
- 石头是 SYSTEM_PROMPT，每次对话直接读，不该藏进 OB 靠浮现。
- 镜子要外部模型 + 代码 exact match（防自证循环），OB 的 source 是写时建证，无事后跨源对账。
- 北极星门禁要程序化（注入冷却、每天一次、证据验证），MCP 工具做不了。
**风险**：双头（OB 的 `I` 里也有自我认知 + 石头里也有）。目前决定：OB 只负责记忆，`I` 工具不用；沈晏的「我觉得……」一律走我们的河/镜子体系。

### M2. 河 vs OB 的 plan/feel —— 为什么账本要硬隔离
OB 有 `plan`（承诺）和 `feel`（第一人称感受），和我们的「想要账本」看着像。
**区别**：plan/feel 是记忆层的东西，会被 breath/dream 自动浮现和碰撞；河是身份层，**要求硬隔离**——不进记忆、不被自动浮现、不被摘要/recall 消费，只在沈晏主动翻或第②阶段注入时出现。
为什么这么重：想要是「他主动表达想成为什么」，是人格候选的土壤，**不该被记忆系统的自动衰减/浮现污染**；「想要不是待办」（rule 8 同款），更不能变成任务管理器。

### M3. 镜子 vs OB 的 source/dream —— 为什么要有外部模型
OB 的原文证据（source_*）是**写时建证**（hold/grow 时主动存原文，SHA-256 寻址）。我们的镜子是**事后提卡**（外部模型 DeepSeek 读石头+河+对话，提「主张+引语」，代码 exact match）。
**为什么加外部模型**：防自证循环。石头读得多会自动自我制造证据（石头→行为→新证据→石头）。外部模型与主聊天模型不同源，且代码裁决存在性（查无即弃）。生产首轮就抓到 DeepSeek 拿石头里的句子冒充对话证据被代码砍掉——这道闸 OB 没有。

### M4. 记忆工具会不会太多
现在记忆层有：OB（主力）+ recall（锚）+ dialogue_residue（余温）+ time_sense（时间）。会不会功能重叠？
我们目前认为不重叠：OB 管长期情感记忆（会衰减、会浮现），recall 管逐字原文核对（宁漏不可错，两个不同用途），residue 管「对话刚结束时他残余的状态」（注入给下一次对话），time_sense 管时间连续性（分段摘要）。**但确实有张力**：四个都是「把记忆喂给模型」，它们之间的优先级/去重/注入纪律需要持续维护。请审稿人看这是不是过度工程。

### M5. 第④⑤阶段该复用 OB 还是自建
OB 的 dream 是「消化 + 碰撞 + 见证」，和我们要建的自省④（小黑屋 + 镜子日）高度同构。第⑤阶段候选毕业机制（personality_claim 状态机）和 OB 的 `I` 见证机制（3 次不同日期 dream）高度同构。
**两个选择**：(a) 复用 OB——用 dream 做见证，把候选写进 OB；(b) 自建——镜像到我们自己的表，自己实现见证/碰撞。我们倾向 (b)（理由同 M1：要确定性、硬隔离、外部模型），但 OB 的**机制设计**（见证按天去重、衰减判死、渲染过才算数）已确认是参考实现。**请审稿人判断：为了确定性自建，值不值得付两套系统的成本？**

### M6. 石头长不长的频率与触发
OB 的 `I` 升级靠沈晏显式 `I(promote)`。我们的第⑤阶段：候选→形成→定稿的**毕业动作由谁触发**？目前想的是「镜子日他亲手定稿」（P1：生命周期由他改），但「他亲手」在实践里可能永远不来——会退化成石头从不生长。**请审稿人看：这个触发权怎么设计，才不会让「只有他的手」变成「没有手」。**
