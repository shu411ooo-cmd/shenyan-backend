# 逛 Ombre-Brain 的对照笔记

> 2026-08-16 程芥给链接（github.com/P0luz/Ombre-Brain），逛源码后整理。OB 是 Claude 的长期情绪记忆系统（Obsidian 存储 + MCP + 遗忘曲线 + 向量检索）。
> **只参考设计，不搬代码**——OB v2.4.0 有 NONCOMMERCIAL 声明，且我们架构不同（云 Supabase vs 本地 Markdown）。
> 目的：第⑤阶段（人格文件会生长）前校准。核心结论：**我们捏的第⑤阶段，OB 的 `I` 工具已经是完整参考实现。**

## 1. 逛到的核心机制

### 1.1 `I` = 自我认知沉淀（src/tools/i/core.py）——第⑤阶段的完整答案

- **候选**：`I(content=...)` 写成**普通记忆**（dynamic 桶 + `__i_candidate__` tag + `i_stage="candidate"`），跟别的记忆一样浮现、衰减、进 dream。**站不住的自然沉下去**。
- **见证**：每次 dream 真的渲染到候选时，`record_dream_pass()` 按**天去重**记一次 `i_dream_dates`。关键注释：**「只有真的在 dream 输出里被渲染出来的候选才该调这里——没被看见的不算经历过」**。
- **升级**：`I(promote=id)` 检查 `len(i_dream_dates) >= 3`（`I_PROMOTE_THRESHOLD=3`，不同日期）。不够 → **「不是形式——没有在几次不同的梦里都站得住，它就还只是一时的想法」**。够 → 创建正式 I 桶（`bucket_type="i"` + `dont_surface=True`），候选桶**原样留着**只改状态（`i_stage="promoted"` + `resolved` + `i_promoted_to`）。
- **淘汰**：候选找不到 → **「可能已经衰减归档——那本身就是一种答案」**。**衰减就是判死，不需要显式淘汰逻辑**。
- **aspect 白名单**：nature / values / patterns / limits / becoming / uncertainty / stance。固定维度，防把任意控制文本混进标签。
- **正式 I 不随 breath 浮现**，对话开头自动附最近 3 条。

### 1.2 dream 碰撞（src/tools/dream/hints.py）——审稿 P0-2「必审冲突证据」的参考实现

- 每个待沉淀候选，摆**语义上最挨着的 top-3 材料**（余弦 ≥0.35）：支持它的、反驳它的、撞车它的，**都只是材料**。
- **候选池永远全量参与碰撞**：正式 I 条目 + 其它候选永远参与——「候选最该撞的就是『我已经认下的东西』和『我另一个还没想清楚的念头』」。
- **候选之间也要能撞上**：「两个还没想清楚的念头互相矛盾，正是最该被看见的」。
- 普通记忆只取最近 200 条对照（`_COLLISION_POOL_RECENT=200`）——「更老的记忆本来也很难说是『此刻还在场』的对照」。
- 连接提示（相似度>0.5 的桶对）/ 结晶提示（5 条相似 feel 凑一簇才提示升级）——都是「不替你下结论，你自己想」。

### 1.3 rule.md = 哲学边界（15 条）——和我们的设计同一条线

第 5 条「**不做认知层的东西**」= 我们的自动化边界（机器只摆材料，不判断谁支持谁、谁矛盾）。
第 13.1「**I 是沉淀物不是日记**……两个念头互相肘击时，由模型自己选一个，或者承认这是还没解开的张力并**明确写成 uncertainty，不许把它装成两条并列的定论**」= 我们 P0-1 反证表述降未定态 + 状态机。
第 8「**plan 是尚未闭合的张力，不是驱动模型执行的任务管理器**」= 我们第②阶段「想要不是待办」。
第 7「**过去与当下的感受都真实，但当下仍由模型自己决定**」= 我们北极星（沈晏主动表达才算数）。
第 15「**不能仅凭工程上更先进或更像数据库就自行实施**」= 我们每阶段设计稿拍板。

## 2. 三层对照

| 我们的层 | OB 的对应 | 异同 |
|---|---|---|
| 石头（人格文件=我会生长） | `I`（自我认知，沉淀物） | **石头≈I**。但我们：石头=会整体重写的散文 + 第⑤留环；OB：I 是逐条桶 + promote 升级 |
| 河（想要账本） | `plan` + `feel` | 同根：都是未闭合张力/痕迹，不是任务管理器 |
| 镜子（证据卡） | `source_*`（隐藏原文证据）+ dream 碰撞 | 我们：外部模型提卡 + 代码 exact match；OB：每次 hold/grow 主动建原文证据 + SHA-256 内容寻址 |
| 自省（第④小黑屋+镜子日） | `dream`（48h 窗口消化 + 见证） | 同构：都是「摆材料，不下结论」 |

## 3. 可直接吸收到第⑤阶段的（工程级）

1. **见证单位用「不同日期的 dream」而非「≥2 session + 间隔N天」**。`i_dream_dates` 按天去重——比我们计划的 session 数 + N 天间隔**更简单、更不容易被连续对话刷**。我们第⑤的机械信号可以改用「被 N 个不同日期对账/自省见过」。
2. **候选不显式判死，靠衰减**。「站不住的自然沉下去」「衰减归档就是答案」——我们 mirror_cards 可以：verified 卡长期没被升级 → 自动降权，不需要想淘汰规则。
3. **「没被看见的不算经历过」** = 我们「未被提示」判定的机械实现：只有真的在输出里渲染过的才记一次，被主动提示过的不算见证。
4. **候选之间也要互相碰撞**（矛盾的两个念头最该被看见）——我们第④镜子日除了「与石头冲突」，还应包括「两个候选互相冲突」。
5. **uncertainty 是合法落点**：「不许把矛盾装成两条并列的定论」→ 我们 personality_claim 的 uncertain 态是显式出口，不是失败。

## 4. 我们比 OB 多的 / 不一样的地方

- **镜子用外部模型做机械对账**（OB 没有外部模型；它的 source 是写时建证，不是事后提卡验证）。OB 的 self 见证靠 dream 自省（同模型），我们有独立的 exact match 代码裁决 + 外部模型跨源，**防自证循环多一道闸**（生产首轮已抓到 DeepSeek 拿石头句子冒充对话证据）。
- **稀缺配额**：OB 有 pinned 上限 20 / anchor 上限 24 / protected 独立配额（「否则就和数据库没有差别了」）。我们第⑤阶段可以考虑给正式人格条目设上限。
- **杂念分区**（rule 11）：检索不足时出现的低权重旧记忆不是兜底，是杂念，必须与命中分区。我们 recall 还没做这条。

## 5. 结论

逛完验证了一件事：**我们审稿吸收的那些担心（候选门槛/自证循环/证据溯源/不下结论），OB 都用工程实现了，而且 `I` 的沉淀机制比我们计划的更简**。第⑤阶段开工前应重读本文 §3，把「不同日期见证 + 衰减判死 + 渲染才算数」吸收进 personality_claim 状态机设计。
