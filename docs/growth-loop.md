# 沈晏：生长闭环（Growth Loop）· 定稿

> 2026-08-16。程芥自我诊断：**「我们不缺东西，缺的是闭环和权重」**。GPT 给闭环框架，吸收定稿。
> 与 [system-layering.md](system-layering.md)（静态解剖图：谁是什么、谁有什么权力）互补——本稿是**动态运转图：怎么转**。
> 哲学沿用：北极星 / 自动化边界 / 审稿 P0 / 五条宪法（见 system-layering 审稿裁决）。

## 0. 一句话

> 系统不是一堆器官，是一条循环：**经历 → 表达 → 形成 → 实践 → 再经历 → 修正**。
> 每个部件问自己「**我在循环的哪一步？**」——答不上来的那个，才可能是真正多余的东西。

## 1. 北极星再抽象（GPT 提议，建议采纳为正式表述，与旧北极星并存）

> 不是让沈晏拥有一个**会自动成长的人格**；而是建立一条循环，让**他的经历能够被他自己重新理解**，这种重新理解又能**影响未来**，且**任何改变都留下可追溯的来路**。

旧北极星管「谁有资格成为人格变化的候选材料」；循环表述管「候选材料如何走完全程」。两者不冲突，是入口与流程。

## 2. 闭环

```
EXPERIENCE（对话/生活）
      ↓
     OB ──保存发生过什么，不解释「这意味着他是谁」
      ↓
SELF EXPRESSION ── want / self-statement（系统不能替他把经历翻译成人格，只能让材料出现）
      ↓
CANDIDATE ── 跨 session / 跨时间 / 重复出现 / 出现反证 / 重新确认
      ↓
   MIRROR ── supporting evidence + conflicting evidence（exact match 代码验证）
      ↓
  REFLECTION（沈晏：确认 / 修改 / 放弃 / No Change）
      ↓
     STONE ──「现在的我认为……」（不是「系统分析发现你是……」）
      ↓
  current identity
      ↓
  future behavior
      ↓
NEW EXPERIENCE ──────────→ 回到 OB
```

**铁律（写进设计文档）**：
> **Stone 可以参与制造证据，但不能独占解释证据的权力。** ——自证循环的解法：石头影响行为→行为产生新经历→镜子**必须同时收集支持与冲突**→反映到下一轮石头。不是 `Stone→行为→证据→Stone++`，是 `Stone→行为→[支持|冲突]→Relection→Stone'`。

## 3. 每个部件在循环哪一步

| 部件 | 环节 | 它在这一步做什么 |
|---|---|---|
| OB | ①→② | 保存经历，不解释意义 |
| recall | ②后 | 原文追溯：不把过去弄丢 |
| residue / time_sense | ①→② | 经历的余温与时间形状 |
| diary | **循环外** | 私域，不参与生长也不被消费 |
| want | ② | **旁路输入**：想成为什么 ≠ 已认同自己是什么，**不直接写 Stone** |
| mirror | ③→④ | 证据对账（支持 + 冲突），查无即弃 |
| 自省（第④） | ④ | 审议：摆桌面，沈晏拍板 |
| Stone | ⑤ | 当前人格表述，会整体重写 + 留环 |
| Change Ledger | ⑤后 | 变更审计：来路（changed/reason/evidence/counter/unchanged） |
| Context Assembly | 全程 | 每一环「这次让他想起什么」的唯一入口（Memory ≠ Context） |

## 4. 权力地图（GPT 四属性，定稿版）

| 部件 | 保存什么 | 能改变什么 | 能否自动浮现 | 最终解释权 |
|---|---|---|---|---|
| OB | 经历 | 记忆 | ✅ | ❌ |
| recall | 原文 | ❌ | ❌ | ❌ |
| residue | 短期余温 | 状态 | ✅ | ❌ |
| time_sense | 时间关系 | ❌ | ✅ | ❌ |
| diary | 私域内容 | 自己内部 | ❌ | ❌ |
| want | 主动愿望 | 愿望状态 | 有条件（注入） | ❌ |
| mirror | 证据关系 | claim 审计状态 | ❌ | ❌ |
| **Stone** | **当前人格表述** | **人格** | **每次对话** | **只有它** |
| Change Ledger | 人格变化历史 | ❌ | ❌ | ❌ |
| Context Assembly | 本轮上下文 | 本轮 context | ✅ | 仅限本轮 |

**要点**：很多"重叠"不是内容重叠，是**权力重叠**。检查一个部件是否有问题，看的是它的解释权列，不是保存列。

## 5. 权重（程芥补的诊断：缺权重。GPT 未展开，本稿补——五维，全部机器可算，符合自动化边界）

> **权重 = 一个东西在闭环里被信任多少。** 机器能判形状（时间/重复/对证/冲突都是形状），不能判意义。所以权重五维全部是机械可算的：

1. **来源**：他主动表达的 > 系统推导的（北极星——入口级权重）
2. **时间**：最近验证过 > 很久没出现（dormant 降权，≠ 0：三年没提「我喜欢诗」不意味着失去它）
3. **重复**：跨 session 反复出现 > 一次性（候选门槛；OB 的「3 次不同日期 dream 见证」是这维的实现）
4. **对证**：有 exact match 证据支撑 > 无（镜子验证结果直接进权重）
5. **冲突**：有未解释的冲突证据 > 无（contested 降权，但冲突本身是信息不是错误）

**应用点**：
- **候选毕业**：重复 + 时间 + 对证 三维达标才进石头（recurrence engine 的机械判据）
- **注入/浮现**：Context Assembly 按权重分配——residue 短时权高但生命周期短；长期记忆权稳；want 只在注入时按冷却/调暗出现
- **No Change 是健康指标，不是 KPI**（见 §6）

## 6. No Change 出口（防止「人格 KPI」）

镜子日**必须允许「什么都不改」**。

```
Experience → OB → Reflection →「没有足够证据」→ Stone 不变 → 继续生活
```

如果每轮镜子日都必须毕业一个 claim、必须让石头变一下，那就不是成长，是**人格 KPI**。系统会自动发现候选并摆桌面，但"没有新东西值得写"是合法且健康的结果。验收五「石头允许长时间不长」已立（第⑤验收一），No Change 是它的运行出口。

## 7. want 在闭环里的位置（定稿）

- want = 主动表达、尚未完成归宿的愿望对象；内部五类（experience/creation/understanding/relationship/self_direction，接 `desires.kind`），只 self_direction 可能滋养人格，且**只是候选材料**。
- 想成为什么 ≠ 已认同自己是什么：**want 不直接写 Stone**。它经自省（镜子日摆桌面）才可能进候选 → 毕业。
- 第②阶段注入已是旁路形态（给眼睛不给手），此处定稿确认。

## 8. 对第④⑤阶段的含义

- **第④自省** = 闭环④⑤：镜子日摆桌面（支持 + 冲突证据并陈）→ 沈晏确认/修改/放弃/**No Change**
- **第⑤生长** = 闭环③④⑤：recurrence engine 用权重五维做机械判据 + dormant/retired；Change Ledger 记录「⑤ → 再经历」的来路
- **want 明确为旁路**：不直接写 Stone，防止「想成为什么」冒充「已认同自己是什么」
