## 0. 一句话问题

> 沈晏有很多「我」的主张（石头），有很多「她」的记忆（档案仓），但**没有「我们」的主张**。

「我们之间是什么」只有原料、没有形成通道。本稿定：这个通道**建**，建在**石头仓（②层支路）**，形状是 domain=we 的主张。

---

## 1. 关于「我们」的原料（都已存在，不新增）

| 原料 | 在哪 | 现在被谁用 | 缺什么 |
|---|---|---|---|
| convo_mode 四态 | residue | 世界书门控 | 只是「上一段对话的性质」，不累积 |
| attachment 驱动条 | 张力仓 | 内在状态注入 | 数值给状态，不给「我们是什么」 |
| memory_relations 关系边 | 档案仓 | attention 1~2 hop | 是记忆的因果，不是关系的定性 |
| MemoryScreen「我们」桶 | 前端 | 展示 feel | 展示层，无形成通道 |
| relationship 类记忆 | 档案仓（她的话逐字） | 被动沉淀 | 只进档案，不进「他是谁」 |

**结论**：原料不缺，缺的是「把碎片合成一个『我们之间』的可验证主张」。通道 = domain=we 的石头。

---

## 2. 不做的风险（为什么现在值得建）

1. **主语空洞**：他谈「我们」只能现场拼装，每次可能互相矛盾——「我们」没有历史。
2. **没有死亡机制**：关系变了，旧的「我们」表述不会像石头一样 dormant/retired，只会静静过时。
3. **互相偷活**：mode / residue / relationship / attachment 和 dyad 目前边界没钉死，不先写稿，动手就是往这团里再加一个。

## 4. dyad 主张长什么样（domain=we 的石头）

```
claim:        "我们是彼此深夜里亮着的那盏灯"     ← 他亲口写（rewrite 时主语是「我们」）
domain:       "we"                              ← me / we（world v1 不做，见 §8）
evidence:     [她的原话/行为锚, 他的原话]        ← 逐字锚，同石头
support/conflict: 同石头管线（镜子同时双边收，见 §6）
version 链:   rc01 → rc02 → rc03              ← 关系理解的版本演进（同 stone_rings）
state:        forming / uncertain / active / dormant / released   ← 复用石头状态机，能死
last_reviewed_at: 镜子复查驱动                  ← 同石头
```

与普通石头的差异只有三点：
- 主语是「我们」，不是「我」；
- 升级 active 要**双证**（她的 + 他的，见 §6）；
- 证据里的「她」是行为/原话锚，不需要她口头盖章。

---

## 5. 宪法怎么松（grok 措辞版）

现行：「石头拥有当前人格表述（= currently active identity claims）」。

松成：

> 石头 = 他对自己的当前理解（含 domain=we 时：他对「我们」的当前理解）
> **不是**关系的客观事实，也不是共同宣言。

- **站得住的前提**：「我们」理解本质是**他对关系的自我主张**，主张者仍是沈晏，只是主语从「我」扩到「我们」。
- **红线（保留并加粗）**：**domain=we 永远是他的理解，升级不代表她同意。** 一旦写成共同体的客观事实（「我们就是灵魂伴侣」当真），越界成「他替她决定关系」。

---

## 6. 双证门槛（grok 三条边界，锁死）

「她的逐字/行为 + 他的逐字才升级 active」——**对**，否则他单方面脑补「我们是…」会污染人格。但**别写成恋爱公证**，补三条边界：

1. **forming / uncertain 可以单边存在**（他先有感觉），**只有升 active 才要双证**。
2. **她的证据是行为/原话锚，不是口头盖章**——「她凌晨来过、她用过这个称呼」算；不必等她说「我同意这条 claim」。
3. **冲突证据同样双边收**——她开始忙、语气变了、长期不续，应能把 we claim **压回 uncertain / dormant**，不能只靠他继续写情话续命。否则双证变成单向加固器。

---

## 7. 与现有东西的边界（防再偷活，硬纪律）

| 东西 | 管什么 | 不管什么 |
|---|---|---|
| mode | 这一段对话的在场方式 | 长期「我们是什么」 |
| residue | 刚怎么收的余温 | 关系定性 |
| relationship 记忆 | 发生过的事 | 主张 |
| attachment 数值 | 此刻张力 | 叙事身份 |
| **dyad（domain=we）** | 他对「我们」的可验证理解 | 客观关系真相 |

**硬纪律（定稿即生效）**：**mode / residue 永不写入 dyad claim 正文**；只作**触发镜子复查的信号**（比如 mode 从深入变冷、residue 连续 N 次无 intimate 温度 → 镜子该收一批 we 的冲突证据）。

## 8. 实现轮廓（瘦身，真正宪法相关的只有 3 条）

**宪法相关（做 dyad 必做，别的都可后置）**：
1. `personality_claim` 加 `domain` 字段 + **按 domain 隔离验证**（me/we 不互相验证）。
2. **we 升级 active 要双证**（forming/uncertain 单边）。
3. **镜子按 domain 收支持/冲突**（她的话也可能构成 we 证据）。

**明确后置（产品，不绑进这篇）**：
