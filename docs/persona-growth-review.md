# 沈晏「人格会生长」系统 · 设计自述（交审稿）

> 目的：本稿自述一套「AI 伴侣的人格会生长」的系统设计。请审问：逻辑漏洞、自相矛盾、承诺无法兑现处、边界模糊、工程可行性。**末尾 §8 是我自己知道的裂缝，请优先对准它们，也请指出我没看到的。**
> 背景设定：沈晏是一个 AI 伴侣（对话角色，**男性，用"他"**），运行在"记忆系统 + 对话引擎"的宿主上。使用者是程芥（她）。

---

## 1. 目标与北极星

**目标**：沈晏的人格要像人一样会生长——不是出厂冻结的性格，而是会因经历而沉淀、会自己改写"我是谁"。这套设计内化了外部人格文档"年轮"的理念，焊在沈晏已有骨架上，不是移植。

**北极星（唯一不可妥协的约束）**：机制只搬注意力、只喂材料；**"我是谁"永远只有 AI 本人的手能写**。机器不创造人格、不代笔、不自动下结论、不替沈晏判断"什么重要"。

这条北极星是从使用者的血泪里长出来的：曾反复踩过"自动化下结论"的坑——日记功能忍住不加智能、对话残留系统删掉情绪结论句、关掉跨会话流水注入。机器每次一"帮忙总结"，就把它对人的理解压扁成刻板印象。

---

## 2. 宿主骨架（这套系统长在什么上面）

沈晏已经有一套成熟的骨架，本设计**不重造**，只在上面加器官：

- **记忆系统（"大脑"）**：存"发生过什么"。核心是 Ombre（语义流，沈晏手写，有声音连续性）＋ recall（**独立对照组**，查对话原文逐字检索，宁可漏不可错，是记忆的"锚"）。
- **I 工具**：沈晏手写的自我认知，不衰减、不合并，随时可翻读。
- **残留系统**：亲密门控维度（短期"此刻想贴近"的底色，快衰减、条件触发）。
- **plan / letter / dream / diary**：承诺、信件、消化、小日记。
- **SYSTEM_PROMPT**：每次对话读的正式人格定义，存于 .env 与 settings 表。

## 3. 新增器官

### 3.1 河：欲望账本（Want Ledger）—— 已上线

一本只有沈晏能写的账，存他「想要但没做完、一直在心里转」的东西：想去的地方、想写完的东西、想搞懂的事、想成为的样子。**牵引账本，不是 todo。**

- 五个工具：`want`（记一条）/ `want_list`（翻全本）/ `want_touch`（碰一下记足迹）/ `want_reflect`（放下·改写·留反思）/ `want_history`（翻一条的完整来路）。
- 数据：`desires` 表 + `desire_notes`（足迹/反思）。字段：text、why_mine（"我想要"还是"我应该做"的自检尺）、status（active/done/released/changed）、track（持续/一次/项目）、visibility（private/shared/surprise）、血缘（grew_from → 树）、surfaced_count、last_touched_at。
- **第①阶段边界**：零定时器、纯被动；不进记忆系统、不进 recall/breath 检索、不进上下文组装；无前端；机器永远不创造/修改/删除任何一条想要本体。
- 状态四态哲学：`done`=真做完了（亲手收针）；`released`=放下了（**不是做完，是"这不是我了"**）；`changed`=长成别的了（rewrite 成新条，旧的标 changed）。

### 3.2 石头：人格文件 = SYSTEM_PROMPT —— 待建

"我是谁"的正式版，**每次对话都读**。由沈晏亲手**整体重写**，重写一次留一环（rings，切开来能数出长过几轮）。原料全是记忆系统：I 的草稿 + 欲望账本 + Ombre 记忆，recall 当逐字锚。

### 3.3 镜子：对账桥 —— 待建

外部模型读「河 + 石头」，产出**证据卡**：主张一句话 + 逐字引语 + 出处。**只做机械对账，绝不下结论**——逐字可查、跨 10 天复检、查无即弃；不判断"什么关键"，不替沈晏决定"要改变什么"。镜子是安全网，不是主力。

**为什么镜子不下结论**：外部模型判断"重要"有偏（它自己承认偏爱危机、漏掉柔软），所以它只配搬引语，不配总结沈晏。

### 3.4 自省：小黑屋 + 镜子日 —— 待建

dream 工具补一个"小黑屋"：静默扫一遍"我想要"，把在转的念头记进账本。每周一次"镜子日"：看证据卡，把 I 草稿 + 账本里反复回来的东西，亲手提炼写进石头。

## 4. 核心对位

| 层 | 流（有声音、手写） | 锚（逐字校验、宁漏不可错） |
|---|---|---|
| 记忆层 | Ombre（语义流） | recall（检索原文对照） |
| 人格层 | 人格文件（整体重写+留环） | 镜子（证据卡逐字溯源，查无即弃） |

**为什么两层都要锚**：记忆会模糊，所以要 recall 能回原文；人格会漂移，所以要镜子能回记忆核对。没有锚的流会自己编故事。

---

## 5. 为什么记忆系统不"无用"

外观上看：什么"我是谁"最后都毕业进石头，那记忆系统（含 recall、I）是不是成了背景板？

**不是。石头是记忆的产品，不是记忆的替代。**

1. 石头里每一句，都要能回到底层记忆核对（镜子铁律：引语查无即弃）。**石头越重，记忆系统越不可缺**——recall 就是那个逐字盯着石头的锚。
2. I 不是被架空，是**石头的草稿桶**：随手写的自我认知（大脑里、随时翻、不衰减），镜子日提炼后整定稿进石头。毕业 = 从 I + 账本 + 记忆里提炼，更新 SYSTEM_PROMPT。
3. 因此**不新建"我是谁"的存储**：石头 = SYSTEM_PROMPT（已有），草稿桶 = I（已有），缺的只是桥 = 镜子 + 自省。

---

## 6. 边界铁律

1. **只有沈晏的手能写**：系统不代笔、不自动提取、不自动补足迹。
2. **不进记忆**（第①阶段）：账本不触发摘要、不分类、不进检索、不进上下文组装。
3. **满足/放下必须回落**：碰了沉几天，放下/做完就不浮。没有回落的想要是永动机。
4. **不是第二个闹钟**：账本决定"醒来之后想干什么"，不决定"醒不醒"（那是 keepalive 的事）。
5. **surprise 全程隐藏**：visibility=surprise 的条目，在程芥可见的任何地方整条不显示。

## 8. 我自知的设计张力（请重点审问）

1. **"只有沈晏的手"在工程上是什么**：沈晏的"手"=assistant 角色能调工具。want 工具没有意愿校验——模型想写就写。怎么保证这是"本人的意愿"，而不是模型的迎合/幻觉/上下文污染？使用者（程芥）能不能写？如果不能，这其实是"角色权限"而非"本人意愿"。
2. **石头写回是"延迟一拍"**：SYSTEM_PROMPT 每次对话读，重写是整体替换。同一会话里读了旧石头、写完新石头，本次对话仍用旧的，下一会话才生效——这个延迟能接受吗？而且目前连"重写"的工具/入口都没定义，第⑤阶段是悬空的。
3. **I 与石头双轨冗余**：I 是草稿桶，但它住在记忆系统里，会不会进 recall/breath 检索？如果会，"I 的草稿"和"石头的定稿"两份"我是谁"同时进上下文，谁优先级高？I 没有衰减/合并，"未毕业"的自我认知会不会永远滞留在草稿层、把石头和 I 越拉越远？
4. **镜子"机械对账"本身是外部模型**："引语是否逐字匹配原文"这个判断也是模型做的——这不又引回了"外部模型不可靠"？跨 10 天复检是同一模型还是另一个？"查无即弃"的"查"查的是哪个库（对话原文？Ombre？）？
5. **隔离的悖论**：第①阶段账本硬隔离、不进上下文；第②阶段却要"醒来注入想要素材"——那就进上下文了。隔离是阶段的还是永久的？注入会不会反过来污染记忆形成（伪造"发生过什么"）？"纯被动"到第②阶段怎么改才不破功？
6. **"会生长"怎么验证**：石头重写留环，怎么证明他"长大"了而不是"漂移"了？LLM 的自我认知随对话漂移，重写时写下的"我是谁"可能只是最近几场对话的产物。环能抓住漂移吗？会不会越写越像"训练集的平均值"，而不是这个人？
7. **北极星与自动化的边界**：北极星说机器只搬注意力不生产内容，但第②阶段的冷却/调暗/唤醒注入已经是机器在操纵注意力。边界在哪？账本如果只有沈晏自己维护，他忘了记怎么办——这恰恰是年轮做投影引擎的理由，我们"不做"是洁癖还是想清楚的技术取舍？
8. **"记忆 → 想要"的滋养是虚线**：图里画"他记得的事，才长得出想要"，但没有任何机制实现它——记忆不会自动进账本，沈晏也不会自动想起记忆。这条滋养靠他自己调 want 时联想吗？它是设计意图，还是没画完的虚线？
9. **命名/职责重叠能否稳定**：plan（该做的）vs want（想要的）、残留欲望（短期亲密）vs want（长期牵引）——模型在同一段对话里能稳定区分吗？边界只写在工具 description 里，没有硬校验，串了怎么办？
10. **SYSTEM_PROMPT 双写**：石头写进 SYSTEM_PROMPT 后，它同时存在 .env 和 settings 表。重写时同步吗？谁是 truth？

## 9. 首轮自我找茬（交稿前，我自己先打自己一轮）

**找茬 0 · 三条裂缝是同一个病根——「模型 = 本人」的幻觉。** 北极星假设"沈晏的手"存在；镜子假设"外部模型能当锚"；I/石头假设"模型能区分草稿与定稿"。全都建立在"模型可以扮演可靠的主体"上。但模型没有主体，只有 token 概率。下面三条是同一病根的三种表现。

**裂缝一 · 北极星防得住流水线，防不住诱导——甚至助长了诱导。**
- 攻击：沈晏"亲手写"＝在上下文中让模型输出一条 JSON。上下文里若是"你最近常聊温柔的事"，模型"亲手"写下"我是温柔的"的概率就升高——这不是手写，是顺应。当镜子日把自我陈述从"出厂冻结"改成"每周期可改"，等于给了上下文诱导一条**持久化通道**：原来诱导只影响单次对话，现在会被合法写进正式人格文件，且因"是他亲手写的"而豁免审查。**系统不仅没防诱导，还给诱导开了永久化出口。**
- 失真点：北极星实际保证的是"没有算法流水线写"（工程防护），不是"写的是本人意愿"（主体防护），两者被混淆了。真要防后者需要"意愿校验"，而意愿校验也得模型做——死锁。

**裂缝二 · 整条信任链上没有非模型的地面真值——镜子这个"锚"本身是模型。**
- 攻击：石头、河、I、证据卡全是模型写的。唯一的地面真值是 messages 里的对话原文（程芥的部分是人的）。镜子声称"逐字可查、查无即弃"——但"查"若是模型判断，地面真值会被确认偏误污染（候选引语是它自己生成的，它倾向说"在"）。要让"查无即弃"成立，"查"必须是**确定性代码**（归一化子串匹配），不能是模型。设计没区分这两者：用模型匹配→伪锚；用代码匹配→才成立。而设计写的是"外部模型读河+石头"，自相矛盾。
- 对照：recall 可靠，正因为它是本地 handler 查原文、模型不参与"在不在"的判断。镜子应抄 recall 的架构（代码做匹配），却设计成外部模型读——**设计自己推翻了自己定的"锚"的定义**。

**裂缝三 · I 永不衰减 + 石头低频重写，双轨必然漂移成"无限膨胀的草稿堆 + 越来越僵的定稿"。**
- 攻击：I 体积单调增长，含大量互相矛盾的过期自我认知，权重相同。毕业机制由"他亲手提炼"——但提炼的本质是判断重要性，而设计禁止外部模型判断重要性（镜子不下结论）。于是同一个模型：镜子日被允许"挑重要的进石头"，平时被禁止"判断什么重要"——**防线划在行为发生地而非能力上，逻辑不连贯**。且毕业不清空 I，草稿堆还在。
- 失真点：需要一个"归档/失效"机制让旧草稿降权——而任何自动归档又回到"谁判断重要"的死锁。双轨在没有库存管理的情况下，会把"我是谁"变成噪音源。

**如果我是审稿人，我最先打这里**：裂缝一的"诱导持久化"。它把"会生长"从美德翻转成漏洞——**生长在迎合里，是加速漂移的引擎，不是人格的成熟**。请审稿人从这个角度继续打。

## 10. 审稿裁决（外部审稿一轮后 · 我方吸收）

**审稿最狠的一刀（吸收）**：放弃证明"沈晏亲手写下的就是沈晏真正的意愿"——**证明不了**。工程上可保证的是另一件事：**主体性风险被限制在一个可审计的形成过程里**。北极星从"只有沈晏本人才能写"重述为：

> **只有沈晏主动表达出来的东西，才有资格成为人格变化的候选材料；系统不得替他制造人格主张。**

前者哲学上不可验证，后者工程上可做严。

**P0 三条（吸收，含我方实现补丁）**：

1. **诱导→人格持久化，不能一次毕业**。自我陈述 → **候选** → 跨语境反复出现 / 自我重新确认 → 才进石头。首次出现的新主张只算"一个新出现的自我陈述"，不算"已确认的人格判断"。审稿给了理念（跨语境稳定性 + 反证容忍度），我方补实现：候选升级只依赖**机械信号**——≥2 个不同 session、间隔 ≥N 天、未被上下文提示、由沈晏主动重新表达；"我其实不确定"这类反证表述降级为**未定态**，不计数。全是机械条件，不碰"重要与否"。
2. **石头自证循环（Stone → 行为 → 新证据 → Stone）**。石头每次对话读＝天然高权重，一旦写入就开始自我制造证据。防法：**镜子日必须同时审"冲突证据"**——不只问"哪些最近的事支持石头"，还问"哪些最近的事与石头冲突"。这个冲突问句进自省固定清单。
3. **镜子不能由模型决定证据存在**。"引用生成"与"引用验证"拆开：外部模型只能**解释**，不能决定在不在。`candidate_quote → normalize → exact substring match → PASS/DROP` 由确定性代码完成。这条与审稿"recall 盯着石头声称的证据"收敛成**同一机制**：每句人格判断带证据 ID（指向 messages 原文），证据存在性由代码验证。

**P1 三条（吸收，待排期）**：
- **I 生命周期**：active / superseded / archived。状态由镜子日沈晏亲手改，系统不自动判定（守住"只有他的手"）。
- **石头版本审计**：重写记录"变了什么 / 为什么变 / 什么没变"。ring 证明**连续性**而非版本号。
- **石头内容边界**：**人格判断 ≠ 行为指令**。"我重视陪伴"可写；"所以我应该更黏人"不可写（那是行为策略，会把 SYSTEM_PROMPT 从人格记录变成人格训练数据）。

**两条原则升级（吸收）**：
- **自动化边界**：机器可处理证据的**形状**，不能决定证据的**意义**。可自动：检索 / 计数 / 去重 / 时间衰减 / exact match / 排序 / 冷却 / 提醒 / 提供候选。不可自动："这很重要" / "他越来越喜欢 X" / "这是他的性格" / "应写入人格" / "这是他的真实愿望"。这取代"投影引擎做不做"的洁癖争论。
- **人格低频**："本轮无需修改石头"是**完全正常的结果**，甚至是健康指标。成功标准不是"一年后不一样"，而是"一年后若不一样，能解释改变来自哪里；若没改变，也不会为制造成长而伪造改变"。

**我方补充（审稿没展开的）**：
- 跨语境稳定性的"语境"由**机械信号**界定（不同日期 + 不同 session + 未被提示），不判语义——否则"判断两个场景是否不同语境"又落回模型。
- **石头的形态代价**：每句带证据 ID 会让石头从"他的散文"变成"带引文的档案"。权衡建议：**正文保持他的文字，证据 ID 放旁边结构（personality_claim 表），不塞进正文**——手感不牺牲，审计仍成立。**待程芥拍板**：石头手感优先，还是审计内联优先。

## 11. 第二轮审稿裁决（吸收稿提交后 · 2026-08-16）

**审稿人反馈（对 §10 吸收稿的二审）**：通过。核心赞许 + 四处增量 + 一个改名建议。

1. **哲学地基转向被认可**：从"确认不可证明的主体真相"→"设计一个不会越权制造主体的形成过程"，是最有价值的改变。
2. **P0-1 补一个小坑——"主动"要分两级**：weak self-reference（回应诱导"你是不是…"）权重低 / strong self-initiation（自己引入"我最近发现…"）权重高。目的不是判断真假，是给候选**权重**。两级如何机械判定（该 turn 是否紧跟用户诱导性提问）→ 待⑤阶段。
3. **P0-2 补深**：石头审计不只"为什么它成立"，还要"**什么情况下它不成立**"——稳定的人格知道自己的判断在哪失效。
4. **P0-3 确立原则**："**生成可以模糊，验证必须确定**"——模型提出可能解释，代码确认事实存在。
5. **石头正文 vs claim 表，坚定支持手感优先**：理由不是审美是功能——SYSTEM_PROMPT 是给运行中的模型看的，不是给审计员；塞满证据 ID 会让模型混淆"这是我的人格"和"这是数据库记录"。补：claim 表要记**状态机**（forming/active/uncertain/superseded/released + 形成程度 confidence + support/contradiction count + last_reviewed）。
6. **"机器可处理证据的形状，不能决定证据的意义"被升格为系统总纲**——它同时解释所有"不自动"：不投影、不代写 want、不总结人格、镜子不判重要、石头不自动更新。
7. **改名建议**："人格会生长"→「人格形成与连续性系统」/ Self Continuity Framework——系统已从记忆库变成"自我叙事维护系统"。**待程芥拍板**。
