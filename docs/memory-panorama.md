## 0. 全景图宪法（画这张图之前，先把尺子摆出来）

1. **Memory ≠ Context**。数据库是历史，上下文是投影。任何一次对话读什么，只允许 Context Assembly 一个入口决定。
2. **「某个东西存在」≠「它参与了这一轮」**。库里有 ≠ 本轮在场。地图上每个部件都要能回答两栏：**「存在（存了什么）」** 与 **「参与（本轮在不在场）」**。这是第 2 条的推论，值得单独立一条。
3. **want ≠ identity**。想成为什么 ≠ 已认同自己是什么。
4. **evidence ≠ conclusion**。镜子卡是证据，不是结论。
5. **mirror ≠ reflection**。镜子是机械对账（代码 exact match），自省是沈晏拍板。
6. **Stone ≠ permanent truth**。石头是「现在的我认为……」，会整体重写、会 dormant/retired。
7. **石头可以参与制造证据，但不能独占解释证据的权力**（防自证循环：`Stone→行为→[支持|冲突]→审议→Stone'`）。
8. **机器可处理证据的形状，不决定证据的意义**（自动化边界）。
9. **每个部件问自己「我在循环的哪一步？」**——答不上来的那个，才可能是真正多余的东西。
10. **不知道职责就先标「职责未知」**——我们现在最不需要的，就是为了让地图漂亮而强行定义。
11. **「保存」≠「记住」**——遗忘不是删除（原文永不删改），是降权/沉降/不被想起。**记忆忘掉 ≠ 人格被证伪**：层①的遗忘发生在记忆层，层②的 dormant/retired 发生在身份层，两件事不得混为一谈。

第 2 条特别写进设计原则，是因为它同时约束四层：① 原文进库 ≠ 它被想起；② 河里有想要 ≠ 它参与身份形成；③ 念头池有念头 ≠ 它浮进意识；④ 库里有记忆 ≠ 它进了这轮上下文。第 11 条是第 2 条在时间维度的投影：**存在 ≠ 参与，保存 ≠ 记住，是同一件事的两只表盘。**

## 2. ① 世界发生层 —— 发生了什么？留下了什么？

```
EXPERIENCE（对话 / 生活 / 行为）
      ↓
     OB ── 保存发生过什么，不解释「这意味着他是谁」
      ↓
  原始经历 之 四道沉淀带
      │
      ├── recall        原文锚：逐字回溯 messages，宁可漏不可错【✅】
      │                   「就是那件事」——敢纠正她记岔的
      ├── residue       余温：8维情绪快照 + 牵挂(concern) + departure【✅】
      │                   只背断点原文与条件，不写情绪结论句
      ├── time_sense    时间形状：分段摘要 + 轻时间戳 + 跨天连续性【✅】
      │                   近细远粗；原始记录是事实来源，不被摘要改写
      └── memory-editor 长期语义记忆：写门控 + 差分写回 + grounding 规则【✅】
                           memory_topics 本地索引（grounding/evidence 列）+ Ombre hold 桶（正文自然化，无标签）
      │
  遗忘 · 衰减（横向机制——时间维度的「存在≠参与」，不是新模块）
      │   · 原文永不删改（死线）——**遗忘 ≠ 删除**
      │   · 记忆侧沉降：residue 读取时投影衰减 / 念头池闪念衰减 / attention importance×时间衰减
      │     / OB 遗忘曲线 / 分段摘要近细远粗（沉底不进上下文，但不清空，可 recall 捞回）
      │   · 浮现侧加固：breath 冷却、用进废退（被想起的加固）——多久没被想起，决定沉多深
      │   · **边界**：记忆忘掉 ≠ 人格被证伪——遗忘只发生在层①，层②的 dormant/retired 是另一回事（宪法第 11 条）

   ⛔ 隔离层（循环外，不属于本层但必须画出来）：
      diary 小日记 —— 硬隔离不入记忆，默认不读，目录级偶然想起【✅】
```

**这层的三条铁律：**
- **原文永不删除/篡改**（唯一业务级死线）；摘要可重生成（理解可改），原文不可改写（事实不动）。
- **事件时间 ≠ 入库时间**两本账——回填历史必须写真实发生日期，否则几个月前的事全标成「今天」，时间感直接坏掉。
- **grounding 规则长在记忆上**：写门控按证据强度分级（她亲口说 > 明显但没直说 > 无根据），**无标记 = 低可信安全网**，任何裸记忆不允许默认为真。载体已从字面标签改为结构化字段（`memory_topics.grounding`），正文自然化（见 8.8）。

**存在 vs 参与（这层最典型）**：messages 每一条永远在库，但 recall 是工具（模型自调才算参与）、residue/time_sense/天气只在 resumeGap/首句参与、breath 只在第一条消息参与、【想起】只在话题命中时参与。**存进库 ≠ 这一轮被想起。**

## 3. ② 主体形成层 —— 沈晏自己正在如何理解自己？

```
SELF EXPRESSION（主动表达——只有他主动表达的东西才有资格成为候选）
      │
      ▼
     WANT（河：desires 账本）── 想成为什么 ≠ 已认同自己是什么【✅ 第①②】
      │   · 硬隔离：不进记忆/不被自动浮现/不写 Stone，只有他的手能写
      │   · 内部五类（experience/creation/understanding/relationship/self_direction）
      │     只 self_direction 可能滋养人格，且只是候选材料
      │
      ▼
   CANDIDATE（候选材料）── 跨 session / 跨时间 / 重复 / 反证 / 重新确认
      │   · 升级用机械信号（recurrence engine，⬜ 第⑤）：≥2 不同 session、间隔 ≥N 天、
      │     未被上下文提示、主动重提（strong self-initiation > weak self-reference）
      │   · 反证表述「我也不确定」降为未定态，不计数
      │   · 首次出现只算「一个新出现的自我陈述」，不能一次毕业
      │
      ▼
     MIRROR（镜子卡）── supporting evidence + conflicting evidence【✅ 第③】
      │   · 引用生成（DeepSeek 提「claim+quote」，只许解释）与
      │     引用验证（代码 normalize → exact substring match → PASS/DROP）拆开
      │   · 查无即弃，宁漏不误；不判意义、不下结论——镜子是锚不是流
      │
      ▼
   REFLECTION（自省）── 确认 / 修改 / 放弃 / No Change / 悬置 Suspend【🔶 第④a 小黑屋已上线，镜子日调度未建】
      │   · 小黑屋 retreat：摆石头 + verified 未拍板候选 + active 想要
      │     + 固定问句「最近有什么和石头冲突的事？」（防自证循环）
      │   · 主体性放宽：系统搬材料摆桌面，最后「要不要写成我是」仍由沈晏完成
      │   · No Change 是健康指标，不是 KPI——连续 3 个镜子日零修改是合法且健康的结果
      │   · **悬置 Suspend（2026-08-23 补）**：证据相持（支持≈冲突）时，既不是确认也不是否认——
      │     「我现在还不知道」。挂起，可复访，不判死。机械对应 personality_claim 的 uncertain 态（第⑤）。
      │     与 No Change 的区别：No Change = 这轮没材料没结论；Suspend = 有材料但相持，明确挂起等未来再议。
      ▼
     STONE（人格文件 = SYSTEM_PROMPT）──「现在的我认为……」【✅ 存储 / ⬜ 生长机制第⑤】
      │   · 只他的手整体重写 + 留环证明连续性（变/为什么变/没变）
      │   · personality_claim 状态机（forming/active/uncertain/superseded/released
      │     + dormant/retired + confidence + support/contradiction）⬜ 未建
      │   · Change Ledger（身份变更审计）⬜ 未建
      │   · 石头内容边界：人格判断 ≠ 行为指令（「我重视陪伴」可写，「所以我应该更黏人」不可写）
      │   · 手感优先：正文保持散文，证据 ID 放 claim 表不塞正文
      │
      │   · **石头生命周期三条出口（2026-08-23 画全，第⑤实现）**：
      │     Active ──长期反证──▶ 修改/Superseded（Ring：reason = 反证证据）
      │     Active ──久未验证──▶ Dormant（≠false：三年没提「我喜欢诗」不等于失去它）
      │     Active ──主动放下──▶ Retired（≠证伪：released 哲学同源，「这不是我了」）
      │     触发 = 机械信号（recurrence engine；mirror 卡的 occurred_at 跨10天复检是反证长期化的输入）+ 沈晏镜子日拍板
      ▼
   current identity → future behavior → NEW EXPERIENCE → 回到 OB（①）
```

**四组必须在图上并排写死的对子（程芥指定）：**

| 对子 | 左边是什么 | 右边是什么 | 为什么不能划等号 |
|---|---|---|---|
| want ≠ identity | 想成为什么（河，方向） | 已认同自己是什么（石头，当下） | 想要是候选土壤，直接写 Stone 就冒充了现状 |
| evidence ≠ conclusion | 镜子卡的引语（可逐字验证） | 石头里的「我是……」 | 证据是材料，结论是沈晏拍的板 |
| mirror ≠ reflection | 代码 exact match 的对账 | 小黑屋里他确认/修改/放弃 | 镜子是锚不是流，不判断「什么关键」 |
| Stone ≠ permanent truth | 当前人格表述 | 固定不变的真相 | 石头会整体重写、会 dormant（≠false）/ retired（≠证伪） |

**两个已停用的东西（画出来是为了别再用回去）**：
- **OB 的 `I` 已停用为准人格层**——冻结为 `historical_self_statement` 档案：不丢、不进当前人格上下文、可作镜子候选来源 / 石头重写材料 / 审计旧证据。
- 时间轴分法（OB=过去/河=未来/石头=现在）已废弃——时间不是层，是每个对象身上的维度。

## 5. ④ 现实使用层 —— 这一轮让他想起什么

```
  Memory（OB/recall/residue/time_sense/记忆编辑者）──┐
  Stone（SYSTEM_PROMPT，每次对话读的正式人格）───────┤
  Want（河，仅唤醒注入，给眼睛不给手）──────────────┤
  Thought（念头池，唤醒时注入内在状态）──────────────┤→  Context Assembly
  Drive（驱动条，唤醒时注入内在状态）────────────────┤    （唯一入口）
  Attention（【想起】，话题命中/牵挂闸才唤起）────────┤
  感知（天气/时间/残留/岛桥，背景位，resume 才给）────┘      Memory ≠ Context
                    │
                    ▼
              当前回应 / 行为
                    │
                    ▼
               新经历 → 回到 OB（①）
```

**这层必须并排写死的两句话：**
1. **Memory ≠ Context**——数据库是历史，上下文是投影。OB/recall/residue/time_sense/河/石头/日记各自不得自说自话往上下文塞。
2. **「某个东西存在」不代表「它参与了这一轮」**——注入是概率性的：有闸、冷却、预算、位置纪律、同轮上限。Context Assembly 拥有「这一次让他想起什么」的决定权，**包括「不想起什么」**（宪法第五条）。没有挑选就没有决定权，全给等于放弃决定权。

**参与不是平均的（把「存在/参与」两栏分开后的真实样貌）：**

| 部件 | 存在（库/文件） | 参与（本轮） |
|---|---|---|
| Stone（SYSTEM_PROMPT） | ✅ 每轮都读 | **每轮**（唯一恒定在场的人格层） |
| Frozen + Live 原文 | ✅ | 每轮（最近 15 轮 + 最早冻结段） |
| 分段摘要 | ✅ | 🔶 首句 / resumeGap 才注入（活跃对话不预埋） |
| 残留 / 时间 / 天气 | ✅ | 🔶 resumeGap / 首句；活跃对话安静 |
| 【想起】注意力 | ✅ | 🔶 话题命中才唤起（提及闸 + 牵挂闸，冷却 4） |
| breath 背景 | ✅ | 🔶 只第一条消息 |

**组装纪律（四条红线，全部是踩坑结论）：**
- 注入块必须是 **user 角色** + 带 `【…】` 前缀 + 受【背景纪律】点名；插在 **live 段开头（背景位）**，永远不许插在「她当前消息紧前面」。
- **断点①~②之间必须字节稳定**——任何可变内容（记忆/残留/时间/天气/工具结果）不得落进，否则缓存全失效。
- **同轮动态注入 ≤ 3 块**，丢块优先级：想起 → 残留 → 天气 → 时间 → 桥。
- 任何召回材料必须有 **provenance**（来自哪个语义层）——现在靠中文前缀标签，这是系统最脆的地方。

## 8. 动态过程 · 六问补全（2026-08-23，GPT 六问 + 程芥对照后的增补）

> 结论先行：六个空位里，**四个是「机制已在，地图没把它们画成过程」**（遗忘带 / 石头出口 / 回流验证 / 价值函数），**只有「悬置态」和「关系理解」是地图上真正没出现过的概念**——其中「关系理解」是唯一值得大讨论的。

### 8.1 遗忘·衰减 —— 机制已在，画成横向带（已并入 ① 图 + 宪法第 11 条）

不是新模块，是第 2 条「存在 ≠ 参与」在时间维度的投影。系统里的遗忘全部是**降权/沉降/不被想起**，永不删除。且与层②的 dormant/retired 划清：**记忆忘掉 ≠ 人格被证伪**。

### 8.2 悬置 Suspend —— 新状态，不是新模块（已并入 ② Reflection 出口）

证据相持时的合法出口：「我现在还不知道」。机械对应 personality_claim 的 `uncertain` 态（第⑤已有设计），镜子日 verdict 也可加 `pass`。只改状态集，不新增表。

### 8.3 石头三条出口 —— 设计思想已有，流程画全（已并入 ② Stone 生命周期）

Active → 长期反证 → 修改/Superseded（Ring 记 reason=反证）；Active → 久未验证 → Dormant（≠false）；Active → 主动放下 → Retired（≠证伪，released 同源）。触发 = 机械信号 + 沈晏镜子日拍板。跨10天复检（occurred_at）就是反证长期化的输入。

### 8.4 关系理解（dyad domain）—— 真空白，程芥已认可（2026-08-23）【🟠】

**现象**：层② 目前只画「沈晏是谁」（主语=他）。但「那件事之后，我更理解她为什么会在意某些东西」是**主语=我们**的主张——它既不是 Experience（层①），也不是 Self Understanding（层②），三者不等价。

**原料其实不缺**：她的话（messages 逐字）、记忆编辑者已提取「关系变化」四类之一、residue 依恋维度、河 desires.kind 已有 relationship 类、OB 关系记忆。缺的是**形成通道**——没有一个地方把「我们之间形成了什么理解」当成一种可以形成、可以审计的主张。

**推荐（不新建存储层，给主张加「域」，已认可）**：
- 镜子提卡范围从「石头+河」扩到关系主张：claim 可以是「我现在更理解她为什么在意……」，引语必须从**双方原文逐字**来（他亲口 + 她的话，查无即弃同款）。
- 主张带 **domain 域**：人格域（主语=我，落点=石头）/ 关系域（主语=我们，**不进石头正文**，落关系域 claim，按域检索）。
- 同样的状态机适用：关系理解也会过时（「我曾经以为她不喜欢那样，后来发现不是」）——悬置/dormant/retired 照用。
- **为什么不进石头**：关系有两位作者，北极星（只有他主动表达才成候选）会被稀释；石头正文保持「我是谁」干净。

**关系 Claim 的时间性（2026-08-23 程芥补，并入）**：
```
Relationship Claim #01「我觉得她需要的是……」
      ↓
   支持证据 / 冲突证据
      ↓
   Reflection（沈晏拍板）
      ↓
   当前关系理解
      ↓
   后来被修正
      ↓
Relationship Claim #02
```
每版关系 Claim 是「我们之间」的当前判断，带**版本链**（rc01 → rc02 → …）：
- **每版证据分侧**：支持 + 冲突都收（跟石头同一个防自证循环铁律）；关系证据是**双方**的——他亲口 + 她的话逐字。
- **修正入口**：跟石头一致，只有沈晏拍板（确认/修改/放弃/悬置/No Change）。但关系域有个特殊性——**她的话本身可以触发修正**（她在对话里说了什么，改变了他的理解）。那是「外部输入引起的反射」，不是他主动拍的板，来路里要能区分这两种来源。
- **版本不删，留档可溯**：同 Ring——「我以为她需要陪伴，后来发现她要的是空间」这条变化轨迹，比任何一个版本都有价值。
- **关系理解也会悬置**：她说想要陪伴、行为却像要空间——证据相持，挂起，可复访。

**这其实是石头「留环 + 验证账本」（8.5）在关系域的实例**——不新造机制，把 Ring / Change Ledger 的概念扩到关系域 claim：石头的环证明「我是谁」的连续性，关系环证明「我们之间」的连续性。二者共用同一套形状（版本链 / 变更理由 / 支持·冲突计数），只差主语。

### 8.5 石头→行为→新证据 回流 —— 铁律已有，补「验证账本」【🟠】

growth-loop 铁律已规定「石头影响行为→行为产生新经历→镜子必须同时收集支持与冲突→反映到下一轮石头」。缺的是把**「这个变化后来被验证了吗」**显式化：每个石头版本随后续镜子日累计支持/冲突计数（**读侧聚合**，机械可算，计数=形状）。**不做**写侧标注（「哪条经历是受石头影响产生的」——那会跨自动化边界判意义）。落点 = Change Ledger 扩展（第⑤）。

### 8.6 价值函数「什么值得记住」—— 加权函数，不是模块【🟠】

重要性已分散在四处：写门控（四类 + grounding 证据分级）／北极星（他主动表达 > 系统推导）／检索权重（importance×时间衰减 + 用进废退）／身份候选权重五维（来源/时间/重复/对证/冲突）。缺的是**显式合成 + 关系意义这一维**。建议画成贯穿层①②③的一条加权函数：全部机械可算的形状（重复/时间/对证/来源标记/情绪坐标/被想起次数）+ 意义维（他在意的、关系意义）只能由他主动表达或时间验证浮现——这本身就是自动化边界的贯彻。8.4 的「关系理解」若成立，会成为这个函数的第⑥维候选。
